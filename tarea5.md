Normalización de bases de datos

Proceso que nos ayuda a diseñar bases de datos que organizan estructuras específicas.
Podemos mejorar la legibilidad y almaceamiento de dichos datos, aparte de prevenir anomalias y minimizar las anomalias.

Esto nos ayuda en la optimización general en la gestión de bases de datos. Empresas e instutuciones en todo el mundo dependen de las bases de datos para gestionar y tener un buen manejo de su infromación. La normalización de datos siempre ha sido crucial para este tipo de entidades y no es algo nuevo.

En una base de datos, las claves son indispensables ya que se emplean para identificar las diferentes datos que hay en la base de datos.

Para organizar dichas tablas existe lo que se le conoce como formas normales de normalización de bases de datos. Hay diferentes formas por lo que daremos un breve resumen de cada una.
1. Primera formal normal: eliminamos los repetidos y evitamos tener una celda con varios valores.
2. Segunda forma normal: hace que los atributos dependan de la clase primaria.
3. Tercera formal normal: hace que un dato no clave dependa de otro dato no clave.
4. Cuarta forma normal: elimina las dependencias multivalor, separando relaciones independientes.
5. Quinta formal normal: busca una tabla que se pueda dividir y reconstruirse sin perder información ni generar datos incorrectos.
